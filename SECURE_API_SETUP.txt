SECURE API SETUP

This version keeps the API-Football key out of the browser.

1. Deploy this project to Netlify.
2. In Netlify: Site configuration -> Environment variables.
3. Add:
   Name: NETLIFY_API_KEY
   Value: YOUR_API_FOOTBALL_KEY
4. Redeploy the site.

The browser calls /.netlify/functions/football-api and the function adds the secret server-side.

IMPORTANT FREE-PLAN FIX:
The Free API-Football plan rejects the `last` fixtures parameter. The Value Scanner therefore uses the supported `team + season` fixture list, filters completed matches before the selected fixture, sorts them newest-first, and uses up to 20 where available. This also caches each team's season history during a scan to reduce API requests.

The Free plan is limited to 100 requests/day, so scanning many fixtures can still use the daily quota.

If the key previously posted in chat is still active, regenerate it and use the new key in Netlify.
